# GOROS Modules

GOROS is built using modular architecture.

Every module owns its own:

- API
- Database Models
- Services
- Repository
- Schemas
- Tests

Modules communicate using interfaces.

The initial modules are:

- Identity
- Organizations
- Users
- Conversations
- Chat
- Agents
- Prompt Library
- Knowledge Bases
- Documents
- File Processing
- Embeddings
- RAG
- Memory
- Tool Registry
- MCP
- LLM Gateway
- Model Management
- Usage Tracking
- Billing
- API Keys
- Webhooks
- Audit Logs
- Settings
- Admin
